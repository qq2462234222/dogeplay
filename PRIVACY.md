# dogeplay Privacy Policy

Last updated: 2026-10-22

dogeplay is a free, open-source Windows application maintained by doge. It
does not require an account and does not collect telemetry.

## Local data

Music files, playlists, settings, playback history and downloaded scores are
stored locally on the user's computer. The application does not upload these
files unless the user explicitly chooses a website download or another
user-requested operation.

## Website and update access

The application can request public score catalogs, public score files,
release metadata, announcements and update packages from the URLs selected by
the user or configured by the maintainer. These requests may include the
user's IP address as required by normal Internet connections.

Login pages are displayed in an isolated Microsoft WebView2 profile. The
application does not extract, read or transmit browser cookies, passwords,
authentication tokens or saved login data.

## Game input

When the user starts playback, dogeplay sends the configured keyboard input
needed for the selected music instrument. It does not modify game files,
disable security software or bypass anti-cheat protections.

## Third-party services

Third-party score websites, Microsoft WebView2 and the Audiveris recognition
engine are subject to their own licenses and privacy policies. Their use is
initiated by the user or by the explicit features selected in dogeplay.
